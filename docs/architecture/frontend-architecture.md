# Frontend Architecture

## Goals

The frontend should remain loosely coupled to backend implementation details.

## Principles

- Feature-based organization
- Centralized API communication
- Reusable UI components
- Clear authentication state
- Server state separated from local UI state
- Environment-based configuration
- Avoid business rules duplicated across pages

## Future

The frontend should be able to consume new organization and role capabilities without requiring a complete rewrite of existing screens.
