# Project Overview

## What is the Project?

This project is an AI-powered platform focused on interactive learning, practice, and guidance through realistic conversations and role-based experiences.

The product is designed to move beyond static content by allowing users to interact with an AI system, maintain conversation context, and receive useful responses based on the current session.

## Core Principle

> Practice through interaction, retain context, and improve through feedback.

## Product Direction

The system is intentionally being built in a modular and loosely coupled way so that additional organization types, roles, AI capabilities, and product features can be introduced without requiring a major architectural rewrite.

## MVP Focus

The MVP prioritizes:

- User authentication and account management
- Core user experience
- Conversational AI foundation
- Conversation/session persistence
- Extensible role and organization concepts
- A clean API and application architecture

Features that are not required for the MVP should remain isolated so they can be introduced later.
