# Features

## MVP Features

### Authentication

The platform requires a secure authentication foundation for user registration, login, token handling, and protected resources.

### User Management

Users have a central identity that can later participate in different organization and role contexts.

### Conversation

The platform maintains conversational interactions between the user and the AI system.

### Conversation History

Conversation history is persisted so that relevant context can be restored instead of treating every request as an isolated interaction.

### Extensible Roles

Roles are designed as a future-ready concept rather than being permanently tied to a single organization type.

### Organization Support

The architecture is intended to support different organization types such as companies, universities, schools, and other institutions.

## Future Features

Potential future capabilities include:

- Advanced role management
- Organization administration
- Personalized AI experiences
- Evaluation and feedback
- Progress tracking
- Analytics
- Additional AI agents
- Voice interaction
- Rich organization workflows

Future features should be added without changing the core user identity model unnecessarily.
